# Security Policy

## Supported Versions

Currently, only the latest release of Aegis-PQC is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in Aegis-PQC, please report it to us via private disclosure or email. We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If a fix is accepted, we will coordinate the public release of the fix and, if applicable, the publication of a security advisory.
